# موقع دعوة زفاف إلكترونية تفاعلية وفاخرة 💍✨

موقع ويب متكامل وفاخر لدعوة زفاف إلكترونية، مستوحى من التراث العربي والإسلامي الأصيل، مخصص لمناسبة زفاف نجليهما:
**صدام حسين المرعي & كريمة السيد محمد قناطري**.

---

## 🌟 مميزات الموقع وتجربة الاستخدام

1. **شاشة الافتتاح بالظرف الرقمي ثلاثي الأبعاد (3D Interactive Envelope):**
   - تصميم مظروف ملكي بختم شمعي ذهبي ("فرحتنا").
   - حركة انسيابية تحاكي فتح المظروف وانزلاق بطاقة الدعوة للأعلى.
   - البسملة وعنوان "دعوة لحضور فرحة العمر" واسم العريس.
   - خيار "إعادة فتح الدعوة" لعيش التجربة مجدداً في أي وقت.

2. **الآية القرآنية الكريمة (سورة الروم - الآية 21):**
   - بخط عربي أصيل (Amiri) مع إطار وقوس إسلامي وزخارف هندسية دقيقة.
   - نص الآية المعتمد والمضبوط بالشكل دون أدنى تغيير.

3. **أصحاب الدعوة والعروسان (المحور البصري الأساسي):**
   - إبراز عائلة المرحوم حسين المرعي والسيد محمد قناطري.
   - بطاقة العروسين الملكية بإطار ذهبي مزدوج مع فاصل زخرفي بديع.
   - أسماء العروسين واضحة تماماً: **صدام حسين المرعي** و **كريمة السيد محمد قناطري**.

4. **تفاصيل المناسبة والترتيبات:**
   - بطاقات معلومات أنيقة بأيقونات ذهبية.
   - يوم الجمعة 30 أكتوبر 2026.
   - موعد ونقطة الانطلاق: الساعة الخامسة عصرًا من منزل العريس.
   - ترتيبات الاستقبال: صالة مخصصة للرجال وصالة مخصصة للنساء.

5. **العد التنازلي المباشر (Live Countdown):**
   - يحسب تلقائياً وبدقة: الأيام، الساعات، الدقائق، والثواني حتى موعد الانطلاق.
   - عند حلول الموعد، يتوقف تلقائياً ويعرض رسالة مباركة ترحيبية دون ظهور أي أرقام سالبة.

6. **موقع الصالة ومرونة رابط الخرائط:**
   - صالة ليالي النجوم (غربي كفر عويد، شمال طريق الرام).
   - زر "عرض الموقع على الخرائط" مهيأ تقنياً؛ في حال عدم وجود رابط يكون غير نشط وبملاحظة أنيقة، وبمجرد كتابة الرابط في ملف الإعدادات `config.js` يتحول تلقائياً إلى زر ذهبي فعال دون لمس كود HTML أو CSS.

7. **ملاحظة الخصوصية ومنع التصوير:**
   - بطاقة تنبيهية واضحة ومحترمة تمنع التصوير في صالة النساء حفظاً للخصوصية.

8. **نموذج تأكيد الحضور (RSVP) الذكي والصادق:**
   - حقل اسم المدعو الكريم (مطلوب مع تحقق فوري).
   - أزرار اختيار الحالة: (سأحضر بكل سرور / أعتذر عن الحضور).
   - إظهار حقل "عدد المرافقين" فقط عند اختيار الحضور وإخفاؤه تلقائياً عند الاعتذار.
   - تحقق صارم يمنع النصوص أو الأرقام السالبة.
   - شفافية تامة: في حال عدم ربط سيرفر، يتيح للضيف إرسال رده مباشرة إلى واتساب العريس بنقرة واحدة، وتظهر بعدها رسالة الشكر الرسمية المعتمدة:
     *"شكرًا لمشاركتنا فرحتنا. نسأل الله أن يديم عليكم الأفراح والمسرات، وأن يجمعنا وإياكم دائمًا على الخير والمحبة."*

9. **إضافات راقية:**
   - زر "إضافة إلى التقويم" (يفتح Google Calendar أو يحمّل ملف `.ics` المتوافق مع iPhone وOutlook).
   - زر "مشاركة الدعوة" (يدعم Web Share API على الهواتف ومشاركة واتساب مباشرة).
   - زر "نسخ رابط الدعوة" مع إشعار توست (Toast Notification) أنيق.
   - زر نغمة ترحيبية هادئة (Web Audio API) بدون أي ملفات خارجية ثقيلة.
   - زر العودة للأعلى عائم يظهر عند التمرير.
   - دعم كامل لـ `prefers-reduced-motion` للأشخاص الذين يفضلون تقليل الحركات.

## 🚀 كيفية تشغيل المشروع محلياً

المشروع مصمم ليعمل **فوراً بدون الحاجة لتثبيت أي برامج أو حزم Node.js**:

### الطريقة الأولى: الفتح المباشر
- قم بالدخول إلى المجلد وافتح ملف `index.html` في أي متصفح (Chrome, Safari, Edge, Firefox).

### الطريقة الثانية: باستخدام سيرفر بايثون المحلي
إذا أردت تجربة بيئة السيرفر المحلي الكاملة:
```bash
cd "C:\Users\Samer Alhalib\.gemini\antigravity\scratch\wedding-invitation"
python -m http.server 8080
```
ثم افتح المتصفح على الرابط: `http://localhost:8080`

## ⚙️ كيفية تعديل بيانات المناسبة وإضافة رابط الخرائط

تم فصل جميع البيانات في ملف واحد نظيف وسهل التعديل:
👉 `js/config.js`

### 1. إضافة رابط الخرائط (عند توفره)
افتح `js/config.js` وابحث عن السطر الخاص بـ `mapsUrl`:
```javascript
// قبل التعديل (فارغ حالياً):
mapsUrl: "",

// بعد التعديل (ضع الرابط الحقيقي):
mapsUrl: "https://maps.google.com/?q=صالة_ليالي_النجوم_كفر_عويد",
```
بمجرد حفظ الملف، سيتحول زر الخرائط في الموقع تلقائياً إلى زر ذهبي نشط ويفتح خرائط جوجل مباشرة!

### 2. تفعيل رقم واتساب لاستقبال تأكيدات الحضور
في ملف `js/config.js`:
```javascript
// ضع رقم الهاتف مع المفتاح الدولي بدون إشارة +
whatsappNumber: "963912345678",
```

### 3. ربط نموذج تأكيد الحضور بسيرفر أو قاعدة بيانات (Backend)
إذا أردت حفظ الردود في Google Sheets أو قاعدة بيانات Supabase / Firebase أو عبر خدمة مثل Formspree:
```javascript
endpointUrl: "https://formspree.io/f/YOUR_FORM_ID",
```
الموقع مجهز لإرسال بيانات الـ JSON التالية تلقائياً عند الضغط على إرسال:
```json
{
  "guestName": "اسم الضيف",
  "status": "attending",
  "statusArabic": "سأحضر بكل سرور",
  "companionsCount": 2,
  "timestamp": "2026-10-30T17:00:00.000Z"
}
```

## 🌐 النشر على GitHub Pages

الموقع جاهز 100% للنشر المجاني السريع على GitHub Pages:

1. قم بإنشاء مستودع جديد على GitHub باسم مثلاً: `wedding-invitation`.
2. ارفع ملفات هذا المجلد كاملة إلى المستودع.
3. ادخل إلى **Settings** في مستودع GitHub.
4. من القائمة الجانبية اختر **Pages**.
5. تحت قسم **Build and deployment**:
   - Source: `Deploy from a branch`
   - Branch: اختر `main` والمسار `/(root)`.
   - اضغط **Save**.
6. خلال دقيقة سيظهر لك رابط الموقع العالمي الذي يمكنك مشاركته مع الضيوف عبر واتساب ورسائل الدعوة.

## ✅ الاختبارات والفحوصات المنفذة

تم اختبار وفحص العناصر البرمجية والتصميمية التالية بنجاح:
1. **تجربة فتح الظرف:** عمل حركة كسر ختم الشمع وانزلاق البطاقة للأعلى والانتقال السلس للصفحة.
2. **العداد التنازلي:** فحص الحساب الدقيق حتى تاريخ 30 أكتوبر 2026 الساعة 17:00، والتأكد من عدم ظهور قيم سالبة.
3. **صحة ودقة البيانات:** مطابقة البسملة، الآية الكريمة، أسماء أصحاب الدعوة، واسم العريس (صدام حسين المرعي) والعروس (كريمة السيد محمد قناطري)، وتفاصيل المكان والانطلاق.
4. **حالة رابط الخرائط:** التأكد من المظهر الأنيق للزر عندما يكون الرابط غير متوفر، واختبار تفعيله الفوري عند تزويده بالرابط.
5. **نموذج الحضور:**
   - فحص إخفاء حقل عدد المرافقين عند اختيار الاعتذار، وإظهاره عند اختيار الحضور.
   - التحقق من رفض إرسال اسم فارغ أو عدد مرافقين غير صالح/سالب.
   - التحقق من ظهور رسالة الشكر الرسمية بعد تأكيد الإرسال.
6. **التجاوب مع الهواتف:** فحص العرض على شاشات الهواتف الذكية بعرض 360px و 390px و 414px والتأكد التام من عدم وجود تمرير أفقي.
